# Hello Kitty Badge 🐱🎀

## Описание

Скрытый бейдж **Hello Kitty** добавляет уникальную рамку вокруг аватара пользователя. При включении этого бейджа:

- ✨ Появляется розовая анимированная рамка вокруг аватара
- 🐱 Котик Hello Kitty "смотрит" из верхнего правого угла аватара
- 🎀 Добавляется милый розовый бантик
- 💗 Декоративные элементы (сердечки, бантики, блестки) анимируются вокруг аватара
- 👐 Белые лапки появляются по бокам аватара

## Как получить бейдж

Это **секретный бейдж**, который выдается вручную администратором.

### Для администраторов

Чтобы добавить бейдж пользователю, используйте скрипт:

\`\`\`bash
node scripts/add-hello-kitty-badge.js <username>
\`\`\`

Например:
\`\`\`bash
node scripts/add-hello-kitty-badge.js john_doe
\`\`\`

## Настройки

После получения бейджа пользователь может управлять им через дашборд:

1. **Вкладка "Бейджи"** - включить/выключить видимость бейджа на профиле
2. **Вкладка "Настройка бейджа"** - управление рамкой Hello Kitty:
   - Включить/выключить рамку вокруг аватара
   - Предпросмотр рамки

## Технические детали

### Файлы

- `components/hello-kitty-frame.tsx` - компонент рамки Hello Kitty
- `db/schema.ts` - добавлен тип бейджа `hello_kitty`
- `components/bio-renderer.tsx` - интеграция рамки в профиль
- `components/dashboard/badge-settings-panel.tsx` - панель настроек
- `components/dashboard/badges-panel.tsx` - управление бейджами

### Конфигурация

Настройки хранятся в `profile.modules.badgeConfigs.hello_kitty`:

\`\`\`typescript
{
  enabled: boolean; // Показывать ли рамку (по умолчанию true)
}
\`\`\`

### Условия отображения

Рамка показывается только если:
1. У пользователя есть бейдж `hello_kitty`
2. Бейдж включен в видимых бейджах
3. В настройках бейджа рамка включена (`enabled: true`)
4. У профиля есть аватар

## Дизайн

Рамка адаптируется под форму аватара:
- **Круглый аватар** - круглая рамка
- **Квадратный аватар** - скругленная квадратная рамка (border-radius: 24px)

Цветовая схема:
- Основной цвет: `#ff69b4` (Hot Pink)
- Акцентный цвет: `#ff1493` (Deep Pink)
- Дополнительный: `#ffb6c1` (Light Pink)

## Анимации

- Появление котика: spring анимация с вращением
- Появление лапок: slide-in анимация с задержкой
- Сердечки и украшения: пульсация и вращение
- Рамка: плавное появление с эффектом scale

## Совместимость

- ✅ Адаптивный дизайн (мобильные и десктоп)
- ✅ Работает с круглыми и квадратными аватарами
- ✅ Анимации на основе Framer Motion
- ✅ Оптимизирован для производительности
