# Расширенная система аналитики

## ✅ Что было сделано

### 1. Новые таблицы в базе данных
- **page_views** - детальные просмотры страниц с информацией о браузере, ОС, устройстве, geo-данными
- **user_events** - события пользователей (клики, скроллы, hover и т.д.)
- **user_sessions** - сессии пользователей с агрегированной статистикой
- **analytics_events** - кастомные аналитические события

### 2. API endpoints

#### POST /api/analytics/track
Универсальный endpoint для отслеживания всех типов событий:

**Типы событий:**
- `pageview` - просмотр страницы
- `event` - пользовательское событие (клик, скролл)
- `session` - обновление сессии
- `custom` - кастомное аналитическое событие

#### GET /api/analytics/advanced
Получение расширенной аналитики текущего пользователя (для личного дашборда)

#### GET /api/admin/analytics
**🔴 ADMIN ONLY** - Глобальная аналитика всего сайта:
- Все посещения всех страниц
- Статистика по всем пользователям
- Топ профилей
- Последние сессии
- Полная статистика событий

### 3. Клиентские компоненты

#### AnalyticsTracker
Автоматический трекинг всех действий пользователя на ВСЕХ страницах сайта:
- ✅ Просмотры всех страниц (не только профилей)
- ✅ Время на странице
- ✅ Клики по элементам
- ✅ Глубина скролла
- ✅ Видимость вкладки

Уже подключен глобально в `app/layout.tsx`

### 4. UI компоненты

#### AdvancedAnalyticsPanel (Пользовательская)
Панель аналитики в личном дашборде пользователя - показывает только его статистику.

#### GlobalAnalyticsPanel (Админская) 🔴
**Админская панель** в `/admin?tab=global-analytics` показывает:
- 📊 **Все посещения сайта** - каждая страница, каждый пользователь
- 👥 **Топ профилей** - самые популярные страницы пользователей
- 🔥 **Популярные страницы** - все URL сайта по посещаемости
- 🎯 **Все события** - клики, скроллы и другие действия
- ⏱️ **Последние сессии** - real-time список активных сессий
- 🌍 **География** - откуда заходят пользователи
- 📱 **Устройства** - desktop/mobile/tablet статистика
- 🌐 **Браузеры и ОС** - технические данные
- 🔗 **Источники трафика** - откуда приходят посетители

## 📊 Что отслеживается

### Глобально на всем сайте:
- ✅ **ВСЕ страницы** - главная, блог, профили, дашборд, и т.д.
- ✅ **Каждое действие** пользователя
- ✅ **Все клики** по элементам
- ✅ **Время на каждой странице**
- ✅ **Полная информация о сессиях**

### Собираемые данные:
- **Страница**: полный путь URL
- **Устройство**: desktop, mobile, tablet
- **Браузер**: Chrome, Firefox, Safari, Edge, Opera и др.
- **ОС**: Windows, macOS, Linux, iOS, Android
- **Геолокация**: страна, город (опционально)
- **Источник**: referrer
- **Сессии**: продолжительность, количество страниц, событий
- **Профиль пользователя**: если это страница профиля

## 🔒 Приватность

Все данные анонимизированы:
- IP адреса хешируются (SHA-256)
- Хранятся только агрегированные метрики
- Нет персональных данных

## 🚀 Использование

### Для администраторов:
1. Зайдите в `/admin`
2. Откройте вкладку **"Глобальная аналитика"**
3. Выберите период (24ч, 7д, 30д, 90д, всё время)
4. Изучайте полную статистику ВСЕГО сайта

### Для пользователей:
1. Зайдите в Dashboard → "Расширенная аналитика"
2. Видите только свою статистику профиля
